9月16日 周三

抵达 Toulouse

倒时差友好的第一晚：入住 Le Grand Balcon，慢走 Capitole 和 Les Carmes。

Toulouse 速写
粉砖、鸭油、飞机
图卢兹白天是玫瑰色老城，晚上是 Les Carmes 的酒馆小街；同一座城既有 cassoulet 西南炖菜和紫罗兰糖，也有 Airbus 总部和早期航空邮政故事。Saint-Exupéry，也就是《小王子》的作者，年轻时就和这里的航空邮政圈有关。这里不要赶景点，最地道的玩法是市场午餐、河边散步、晚上在修道院里听钢琴。
路线 / 时间 / 执行
TLS（Toulouse-Blagnac 机场）→ Le Grand Balcon（Capitole 旁酒店）→ Place du Capitole（市政厅广场）→ Les Carmes（老城餐酒街区）

16:35 抵达 Toulouse

  • Toulouse-Blagnac Airport 是图卢兹主机场；入境、取行李后直接进市区。
  • 机场到 Le Grand Balcon 可打车，第一天不要为了省一点交通费折腾公共交通。

傍晚 入住 + 市中心第一眼

  • Le Grand Balcon 在 Capitole 核心区，先办理入住、放行李、简单恢复。
  • 步行到 Place du Capitole，这是 Toulouse 市政厅广场，也是老城最直接的第一印象。

晚上 Les Carmes

  • 从 Esquirol 沿 Rue des Filatiers / Rue Pharaon 慢慢走到 Les Carmes。
  • Les Carmes 是餐厅、wine bar 和 cocktail bar 很密的老城街区；晚餐加一杯酒即可。

预约 / 营业 / 注意

  • Le Grand Balcon 已订 9/16-9/18；早餐未购买。
  • 第一晚餐厅不强制；Le Genty Magre / L'Heure du Singe 可以当天按体力调整。
  • 今晚目标是恢复，不要为了多打卡牺牲睡眠。
Highlight：Les Carmes 夜晚街区
老城南侧 • 小街、bistro、wine bar、cocktail bar
Les Carmes 是 Toulouse 老城里最适合第一晚落地的街区：不需要“看景点”，而是走进一组粉砖小街、餐馆、酒吧和小广场。它比 Capitole 更像本地人晚上会去的地方，街区密度高但不压迫；倒时差时只要找一顿 bistro、饭后走两条街，就能把 Toulouse 的节奏摸到。
打卡 / 吃喝
Les Carmes 第一晚：预约一顿正餐，再按体力加 cocktail。

正餐

  • Le Genty Magre — 第一晚“正式但不累”的西南法国 bistro；适合鸭、鹅肝、cassoulet 这条线，建议订 20:00 左右。
  • L'Heure du Singe — cocktail bar + 小盘晚餐；如果还在倒时差、不想吃太重，选它更灵活。

饭后一杯

  • Nasdrovia — 更当代的 cocktail 选择，适合一杯季节鸡尾酒后回酒店。
  • Au Père Louis — 1889 年老酒馆，适合老派图卢兹氛围；把它当最后一小杯，不当完整晚餐。
住宿 Highlight：Hôtel Le Grand Balcon
9/16-9/18 两晚 • Capitole 核心区 • Aéropostale / Saint-Exupéry 记忆点
Le Grand Balcon 的特别之处是它把“住在市中心”和 Toulouse 的航空历史连在一起。20 世纪早期 Aéropostale 飞行员从 Toulouse 起飞，把邮件航线推向西班牙、非洲和南美；Saint-Exupéry、Mermoz 这些飞行员都和这里有关。酒店保留/复原了 Saint-Exupéry 记忆点的 32 号房气质，所以它不是普通四星商务酒店，而是住在 Capitole 旁边的“航空时代小注脚”。实际价值也很强：第一晚不用通勤，第二天 Jacobins、Victor Hugo 市场、Garonne 河边都能步行串起来。

9月17日 周四

Victor Hugo Market、Garonne + Piano aux Jacobins

图卢兹最值得的一天：市场午餐、河边黄昏、修道院里的钢琴音乐会。

路线 / 时间 / 执行
Le Grand Balcon（Capitole 旁酒店）→ Marché Victor Hugo（室内市场）→ Garonne / Saint-Cyprien（河边和河西街区）→ Cloître des Jacobins（修道院回廊）

上午 慢起

  • 今天不用早起赶景点，把倒时差的空间留出来。
  • 从 Le Grand Balcon 步行去 Marché Victor Hugo，路程短，不需要交通安排。

11:45-12:00 Victor Hugo 午餐

  • Marché Victor Hugo 是图卢兹市中心最重要的室内市场，楼下买菜，楼上餐厅用市场食材做午市。
  • 11:45 到最舒服；目标是吃西南法国方向：鸭、Toulouse sausage、鹅肝、cassoulet。
  • cassoulet、鹅肝、鸭肉都是重菜，点一个主力 share 就好；晚上还有 Piano aux Jacobins，别中午吃到报废。

下午 Garonne + Saint-Cyprien

  • 沿 Garonne（加龙河）慢走，重点看粉砖老城和河岸光线。
  • 过河到 Saint-Cyprien，这是河西岸更本地、更年轻的街区，适合咖啡、自然酒和短暂停靠。

19:15-20:00 Piano aux Jacobins

  • 19:15-19:30 到 Cloître des Jacobins，也就是 Jacobins 修道院回廊。
  • 20:00 听 Piano aux Jacobins；座位是自由入座，19:15 到不是太早，是为了选座、看空间、让耳朵适应修道院回廊的混响。
  • 这个场地本身就是体验的一半，不要把它当普通音乐厅卡点进场。

预约 / 营业 / 注意

  • Marché Victor Hugo 官方时间：周二至周日 06:00-14:00，节假日含在内。
  • Piano 票已买；PDF 要放手机离线文件。
  • 音乐会前晚餐不要排太重；喝酒放在 Café Manine 或 Les Carmes 周边的轻量备选，不专门跑单一 wine bar。
Highlight：Marché Victor Hugo 午餐
周二至周日早上 • Place Victor Hugo • 二楼午餐是重点
Marché Victor Hugo 不是只买菜的市场，而是 Toulouse 最好理解西南法国饮食的地方：楼下是肉铺、奶酪、海鲜、熟食和紫罗兰甜品，楼上餐厅直接用楼下摊位食材做午市。它的好玩点在“市场和餐厅没有断开”：你看到的鸭肉、Toulouse sausage、鹅肝、cassoulet，很快就会变成楼上的盘子。
Cassoulet Toulouse sausage 鹅肝 紫罗兰特产
Highlight：Garonne + Saint-Cyprien 黄昏
Daurade（河边广场）→ Pont Neuf（老桥）→ Port de Viguerie（河西观景点）
这段的价值在光线和城市尺度。Toulouse 的粉砖建筑下午会变暖，Daurade 河边广场到 Pont Neuf 老桥这一段最适合慢走；过桥到 Port de Viguerie 后，回头看老城、Jacobins 和 Dôme de la Grave 的穹顶，会比在老城内部更能理解“玫瑰之城”的颜色。Saint-Cyprien 也更日常，咖啡、自然酒和小店比主广场少一点游客感。
Highlight：Piano aux Jacobins
20:00 • Cloître des Jacobins • Anna Petrova-Forster
这场的重点不是“又看一个教堂”，而是把钢琴放进 Jacobins 修道院回廊的石材、拱廊和自然混响里。Piano aux Jacobins 本身就是 Toulouse 九月的标志性音乐节，空间感会改变听感：弱音、停顿和尾音会比普通音乐厅更有存在感。票是 Catégorie 1 - Assis / Placement Libre；19:15-19:30 到，给自己一点时间看空间、找座位、安静下来。
听奏指南

曲目：Voříšek: Impromptus op. 7 n°1, n°2, n°4, n°5；Rhapsodies op. 1 n°9, n°3。Schubert: Sonata in A minor D845。官方节目页。

  • Voříšek 不用急着找“大旋律”，重点听突然变暗的和声、舞曲感节奏，以及古典清晰度和浪漫派幻想之间的语气。
  • Schubert D845 是 A minor 的中后期奏鸣曲：第一乐章听反复出现的紧张动机，第二乐章听同一个主题如何换光线，后两乐章听焦虑如何被压进舞步和奔跑里。
  • 现场重点 是 Jacobins 空间的自然混响。不要边听边查资料，把注意力放在弱音、停顿、尾音和石材空间里的回声上。
打卡 / 吃喝
Victor Hugo 午市 + Saint-Cyprien 下午 + 音乐会后小酒。

市场午餐

  • Le Magret — Victor Hugo 二楼优先项；偏鸭、cassoulet 和当日市场菜。明确想吃它就提前电话订；官方写周二至周五午餐 12:00-14:00，和 9/17 周四匹配。
  • L'Impériale — 老牌西南家庭餐厅方向；如果想吃更传统的市场楼上餐厅，选它。

下午停靠

  • Café Manine — Saint-Cyprien 河西街区停靠点；咖啡、自然酒、小盘都合适。

音乐会后

  • Les Carmes — 回到老城南侧，按体力找一杯 cocktail / wine；这里酒吧密度高，适合音乐会后灵活处理。
  • Nasdrovia / L'Heure du Singe — 如果第一晚没去，可作为音乐会后的轻量备选，不需要为了喝酒再跨区折腾。
  • N5 Wine Bar — 旅游局页面仍列周四 18:00-00:00 且可预订，但你查到的 Google 状态有冲突；出发前复核营业状态。若确认开，就把它当音乐会后的 wine bar，不当重晚餐。

9月18日 周五

Toulouse 上午 → Château de Goudourville

上午在 Toulouse 收尾，下午进 Château de Goudourville；抵达后重点是逛城堡、看露台和河谷。

Château de Goudourville 速写
住进法国西南乡间遗产
这不是“参观城堡”，是直接住进法国西南乡间遗产里。白天看城墙、露台和加龙河谷，晚上参加婚礼；最特别的不是外面还有什么景点，而是这两天不用离开城堡。它的爽点是：你不是游客路过古堡，而是把婚礼周末完整放在古堡里过。
路线 / 时间 / 执行
Le Grand Balcon（Capitole 旁酒店）→ Les Carmes / Garonne（老城和河边）→ Toulouse Matabiau（主火车站）→ Valence d'Agen（离城堡最近火车站）→ Château de Goudourville（婚礼城堡）

上午 Toulouse 收尾

  • 退房后把行李寄存在 Le Grand Balcon，不要拖着行李逛。
  • 只做轻量收尾：Les Carmes 小街、Esquirol 一带和 Garonne 河边，不再单独排景点。

中午 取行李 → Matabiau

  • 中午前后回酒店取行李，打车去 Toulouse Matabiau。
  • Toulouse Matabiau 是图卢兹主火车站，去 Valence d'Agen 的火车从这里处理最方便。

下午 火车 → Valence d'Agen

  • 坐火车到 Valence d'Agen，它是去 Château de Goudourville 最方便的铁路落点。
  • 城堡在乡村地带，临时叫车不稳；提前让新人或城堡确认 taxi service，或预订车站接送。

傍晚 抵达 Château de Goudourville

  • 到城堡先放行李，熟悉房间、露台、庭院、泳池和婚礼动线。
  • 今天的重点是从城市旅行切到婚礼周末，不再塞 Carcassonne 或外部小镇。

预约 / 营业 / 注意

  • Toulouse → Valence d'Agen 火车票待购买。
  • Valence d'Agen → Château taxi / 婚礼接送必须提前确认。
  • Le Café Cerise、Allegory Coffee Bar 和伴手礼只作为顺路选择，不为了它们延误火车。
Highlight：抵达后逛 Château de Goudourville
下午 / 傍晚 • 露台、城墙、河谷视野、庭院和泳池
这天真正的 highlight 是下午进城堡后从旅行模式切到婚礼周末。Château de Goudourville 坐在加龙河谷上方，最值得先看的是露台、城墙、庭院和远处河谷；这些不是“顺手拍照背景”，而是接下来两天仪式、晚宴、brunch 的实际舞台。抵达后先放行李，再绕一圈熟悉动线；如果泳池开放、天气够暖，晚饭前就在花园或泳池边慢下来，不再塞外部景点。
打卡 / 吃喝
退房前只做咖啡、Carmes 小街和 Toulouse 伴手礼。

咖啡

  • Le Café Cerise — 靠 Daurade / Pont-Neuf 河边的 specialty coffee，比普通酒店早餐更有 Toulouse 日常感。
  • Allegory Coffee Bar — 如果离 Esquirol 更近，用它作咖啡备选。

小街和市场

  • Marché des Carmes — Carmes 区的小市场，适合退房前轻量补逛。
  • Rue Pharaon — Carmes 里餐馆多的小街，适合顺路走过。
  • Place de la Trinité — 老城小广场，适合最后看一眼 Toulouse 粉砖街区。

伴手礼

  • La Maison de la Violette — 图卢兹紫罗兰主题小店；有地方性，但午间休息，只作为顺路备选。
住宿 Highlight：Château de Goudourville
9/18-9/20 两晚 • 中世纪城堡 • 婚礼周末完整停留
Château de Goudourville 不是“乡下漂亮房子”，而是一座层次很厚的中世纪城堡：这一带名字可以追到 5 世纪西哥特人，11 世纪家族在这里修出带防御逻辑的 V 形堡垒，用两座角塔形成交叉火力。后来它从边境防御点慢慢变成贵族宅邸，文艺复兴时期加入螺旋楼梯，18 世纪又被改得更优雅，露台和大窗把军事建筑变成看河谷的生活空间。婚礼周末住在这里的价值很明确：不用把时间花在接驳上，可以把房间、露台、仪式、晚宴和第二天 brunch 连成一个完整场景。

上午 Nice → Villefranche

  • 从 Nice 坐短程 TER 火车去 Villefranche-sur-Mer，一个夹在 Nice 和 Cap Ferrat 之间的彩色港湾小镇。
  • 重点看港口、老城、Rue Obscure（老城里的暗街/拱廊）和 Plage des Marinières（小镇主海滩）。

午后 Villefranche 午餐 / 海滩

  • 午餐优先放在港口一带，订到 Mayssa Beach 或 La Mère Germaine 再坐下吃。
  • 这天不要只当“散步小镇”；随身带泳衣、水鞋和轻毛巾，天气好就在 Plage des Marinières 下水。
  • Villefranche-sur-Mer 的价值一半在港湾，一半在水里。

下午 Cap Ferrat

  • 按体力加 Cap Ferrat，也就是豪宅半岛和海岸步道区域。
  • 从 Villefranche / Beaulieu 一带转 bus 或直接 taxi；二选一即可：Villa Ephrussi 花园别墅，或一段 Saint-Hospice 半岛短步道。
  • 如果天气热，Villefranche 去 Villa Ephrussi 直接 taxi；别为了省一点公交把体力耗光。

预约 / 营业 / 注意

  • Cours Saleya 旅游局页面列为 2026 年全年开放；周一偏古董市场，周三适合早市。
  • Villa Ephrussi 官方 2026/2/2-11/1：10:00-18:00，最后入场闭馆前 30 分钟。
  • 不要带大包去 Villa Ephrussi；官方写没有 luggage lockers，且大包/行李禁止入内。
  • Mayssa Beach / La Mère Germaine 建议提前订；Chapelle Saint-Pierre 同周再核对开放。
Highlight：Cours Saleya 早市
周三正常市场日 • 老城早晨氛围
Cours Saleya 是 Nice 老城白天最有生命力的一条街：花、蔬果、香料、橄榄、tapenade、socca / pissaladière 这些东西都集中在这里。周一偏古董市场，周三更适合你们看正常早市。早上先来这里，不只是买早餐，而是把 Nice 的意大利-普罗旺斯混合气质先闻到、看到、吃到。
Highlight：Villefranche-sur-Mer
彩色港湾 • Rue Obscure（暗街拱廊）• Plage des Marinières（主海滩）
Villefranche-sur-Mer 的美不在“大”，而在港湾尺度：彩色房子几乎贴着深水港，老城、港口和海滩距离很短，像把 Riviera 压缩成一个可步行的小剧场。Rue Obscure 是老城里很有记忆点的暗街/拱廊，Chapelle Saint-Pierre 由 Cocteau 装饰，像一颗小彩蛋；Plage des Marinières 是主海滩，九月天气好就带泳衣和水鞋。
Highlight：Cap Ferrat / Villa Ephrussi
Cap Ferrat 半岛 • Villa Ephrussi（花园别墅）• Pointe Saint-Hospice（短步道）
Cap Ferrat 和加州海边最大不同是“半岛豪宅 + 蓝色小海湾 + 正式花园”的组合。Villa Ephrussi de Rothschild 是粉色海景别墅和多主题花园，像把 Belle Époque Riviera 的审美做成一个可参观的私人世界；想走路就选一段 Pointe Saint-Hospice / Cap Ferrat 海岸步道，看岩石、松树、海湾和透明海水即可，不要贪心绕完整圈。
打卡 / 吃喝
Cours Saleya 早市 + Villefranche 港口午餐；Paloma 不再作为选项。

早市小吃

  • Cours Saleya — 周三正常早市；吃水果、橄榄、tapenade、socca / pissaladière 一类小吃。

Villefranche 午餐

  • Mayssa Beach — 首选，订露台 12:30 左右；午餐每天 12:00-14:30，官网可订。看港湾吃烤鱼，这顿午餐本身就是 Villefranche / Cap Ferrat 当天的核心体验。
  • La Mère Germaine — 如果想更老派正式海鲜，订这里；港口边的经典餐厅，也有订位入口。

Cap Ferrat 下午

  • Villa Ephrussi — 花园别墅，适合轻松逛，不需要很大体力。
  • Saint-Hospice — 半岛短步道，想走路看海岸线就选它。

Beach-club 备选

  • Paloma Beach — 官网已标注永久关闭，不作为选项。
  • Baia Bella — 想要 beach-club 氛围，改去 Beaulieu 这个 Cap Ferrat 旁海边小镇。
